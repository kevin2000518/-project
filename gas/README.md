# 金煎線上訂單 × Google 試算表 設定教學

官網結帳後，訂單會自動寫進你的 Google 試算表，並寄 Email 通知門市。
整個設定大約 10 分鐘，不需要寫程式。

## 運作方式

```
顧客在官網按「確認送出訂單」
        ↓（傳送訂單資料）
Google Apps Script（gas/Code.gs）
  ├─ 檢查資料、依「商品」工作表重新計算金額
  ├─ 產生訂單編號：GJ20261116-001
  ├─ 寫入「訂單」與「訂單明細」工作表
  └─ 寄 Email 通知門市（可選：寄確認信給顧客）
        ↓
官網顯示訂單編號
```

## 試算表裡會有的工作表

| 工作表 | 用途 |
|---|---|
| 訂單 | 每筆訂單一列。「狀態」欄有下拉選單：新訂單／製作中／可取餐／已出貨／已完成／已取消 |
| 訂單明細 | 每個品項一列，方便統計銷量 |
| 商品 | 商品ID、品名、單價、是否冷凍宅配、是否上架。**後台以這裡的價格計算金額** |
| 門市 | 門市ID 與名稱，需與官網一致 |

## 設定步驟

### 1. 建立試算表並貼上程式

1. 到 [Google 試算表](https://sheets.google.com) 建立一個新的空白試算表，命名為「金煎訂單」。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把編輯器裡原本的程式碼全部刪掉，貼上本資料夾 `Code.gs` 的全部內容，按「儲存」。

### 2. 初始化

1. 在編輯器上方的函式選單選 `setup`，按「執行」。
2. 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是你自己寫的程式，Google 對未審核的程式都會這樣提示。）
3. 回到試算表，會看到「訂單」、「訂單明細」、「商品」、「門市」四個工作表。

### 3. 設定 Email 通知（建議）

1. Apps Script 左側「專案設定」（齒輪圖示）→ 最下方「指令碼屬性」→「新增指令碼屬性」。
2. 新增：
   - `NOTIFY_EMAIL`：門市收通知的信箱，例如 `shop@example.com`（多個用逗號隔開）
   - `SEND_CUSTOMER_EMAIL`：填 `true` 才會寄確認信給顧客；不需要就不要加
3. 按「儲存指令碼屬性」。

> 寄信用的是你的 Google 帳號，免費帳號每天約可寄 100 封。

### 4. 部署成網頁應用程式

1. 右上角「部署」→「新增部署作業」。
2. 左邊齒輪選「網頁應用程式」。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

### 5. 把網址填進官網

打開 `index.html`，搜尋 `ORDER_API_URL`，把網址貼進去：

```js
const ORDER_API_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

存檔、推送到 GitHub，網站更新後就會開始收到真實訂單。
（或把網址交給 Claude，請它幫你填好並合併。）

網址留空時，結帳會維持原本的「模擬下單」，不會送出任何資料。

## 之後要修改時

- **改價格／下架商品**：直接改「商品」工作表（「上架」欄改成 FALSE 就無法下單）。
  記得官網 `index.html` 裡的價格也要一起改，否則顧客看到的金額會和實際不同。
- **改了 Code.gs**：要「部署」→「管理部署作業」→ 鉛筆圖示 →「版本」選「新版本」→「部署」。
  這樣網址不會變，官網不用改。
- **新增門市**：在「門市」工作表加一列，官網 `stores` 也要加上相同的門市ID。

## 安全說明

- 金額一律由後台依「商品」工作表計算，顧客無法竄改價格。
- 顧客輸入的文字若以 `=`、`+`、`-`、`@` 開頭，會加上 `'` 避免被試算表當成公式。
- 表單有隱藏的防機器人欄位。
- 目前不含線上付款，訂單成立後請於取餐或收貨時收款。
- 「寄確認信給顧客」會寄到顧客填寫的信箱，有心人可能用來寄信騷擾他人。若遇到濫用，把 `SEND_CUSTOMER_EMAIL` 刪除即可關閉。
